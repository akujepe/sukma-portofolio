# Sukma Afriando — Learning, Research & Quality Portfolio

A polished, responsive, static portfolio inspired by the editorial case-study architecture of Ferdy Portfolio. The design, copy, palette and content are original and written specifically for Sukma Afriando Muharamsyah.

## Run in seconds

1. Extract the ZIP.
2. Open `index.html` with Chrome, Edge, Firefox or Safari.
3. No npm, account, API key, or build step required.

To publish: upload the folder to Cloudflare Pages (direct upload), Netlify, or GitHub Pages. Set the root directory as the website root. All paths are relative.

For local preview with a dev server (optional):

```bash
python -m http.server 8000
# Open http://localhost:8000
```

## Folder structure

- `index.html` — semantic HTML, SEO metadata and the portfolio sections.
- `styles.css` — responsive design system, color tokens, motion and accessibility.
- `app.js` — case studies, lab proposals, filter logic, dialog interactions, mobile nav and counters.
- `assets/Sukma_Afriando_CV.pdf` — original user-supplied CV, available via download buttons.
- `CONTENT_AUDIT.md` — source and verification notes, plus publication checklist.

## Customize quickly

- Change name, headline, summary and timeline in `index.html`.
- Update the `projects` and `labProjects` arrays at the top of `app.js`.
- Change design colors in the `:root` declaration of `styles.css`.
- Replace PDF in `assets/` with the newest validated CV.
- Add a real portrait only with a photo supplied and approved by the owner; the present visual is a typographic portrait placeholder.

## Verified facts vs proposals

Documented case studies come from the supplied 4-page CV; LinkedIn publicly indexed information is used for current job title, the 2025–26 position and selected additional accolades. The Research & Quality Lab describes future *proposed* projects, clearly labeled and without invented employer results. The current Bintang Pelajar appointment is included without unverified performance statistics or detailed duties.

## Accessibility / privacy

- Native navigation, keyboard-accessible buttons, semantic sections, descriptive labels, high-contrast palette, visible focus outlines, and reduced-motion consideration.
- No analytics or tracking, no external scripts. Google Fonts are optional; system fallback works offline.
- No sensitive student/teacher/employee data, screenshots or internal school reporting have been included.
- The publicly distributed CV contains the contact details already supplied by the owner; review before publishing.
